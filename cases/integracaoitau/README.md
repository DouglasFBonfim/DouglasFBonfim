## 🇧🇷 Português

### Integração bancária — geração de TXT/PIX

**Role / Papel / Rol:** Geração de arquivos para fluxo PIX/banco  
**Stack:** `Delphi/Pascal, HTML auxiliar, arquivos bancários`

#### Problem / Problema
Processos financeiros internos precisavam gerar arquivos no formato exigido pelo banco para operações PIX, sem digitação manual.

#### Solution / Solução / Solución
Ferramenta Delphi que monta o TXT no layout bancário a partir dos dados operacionais, reduzindo erro humano.

#### Highlights
- Automação de arquivo bancário
- Redução de erro manual
- Integração finanças ↔ banco
