## 🇧🇷 Português

### DTC Frota Web — frontend de frota

**Role / Papel / Rol:** Frontend web + alertas + dashboards de tanque/frota  
**Stack:** `Python (Flask), HTML/JS/CSS, PostgreSQL, e-mail/alertas`

#### Problem / Problema
Operadores precisavam monitorar tanques, abastecimentos e status de serviços em tempo quase real, com alertas por e-mail.

#### Solution / Solução / Solución
Interface Flask responsiva com dashboard, CRUD de depósitos, medições, conversão de tanques e alertas inteligentes por produto.

#### Highlights
- Dashboard tempo quase real
- Alertas por e-mail com gráficos
- Integração com backend Delphi
