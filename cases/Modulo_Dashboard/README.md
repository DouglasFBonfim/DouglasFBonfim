## 🇧🇷 Português

### Módulo Dashboard — BI operacional

**Role / Papel / Rol:** Frontend web + backend Flask do dashboard  
**Stack:** `Python (Flask), TypeScript, HTML/CSS/JS, charts`

#### Problem / Problema
Operação precisava visualizar indicadores e status em tempo quase real, com tema claro/escuro e layout de dashboard usável no dia a dia.

#### Solution / Solução / Solución
Desenvolvi o módulo web do DTCSync com Flask e frontend moderno (TS/JS), logs rotativos e execução local via scripts Windows.

#### Highlights
- Dashboard com tema claro/escuro
- Stack híbrida Python + TypeScript
- Foco em operação diária
