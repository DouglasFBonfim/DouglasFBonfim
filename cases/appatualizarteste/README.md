## 🇧🇷 Português

### GitHub Updater — componente Delphi

**Role / Papel / Rol:** Protótipo/componente reutilizável de autoatualização  
**Stack:** `Delphi, GitHub Releases API`

#### Problem / Problema
Apps Delphi precisavam verificar e baixar updates do GitHub de forma reutilizável, antes de levar o padrão ao produto final.

#### Solution / Solução / Solución
Componente TGitHubUpdater com UI de teste: owner/repo/versão, comparação e download de release.

#### Highlights
- Componente reutilizável
- Base do auto-update em produção
- Integração com Releases
