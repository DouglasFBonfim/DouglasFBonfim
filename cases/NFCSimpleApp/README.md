## 🇧🇷 Português

### DTC Frota Auxiliar — NFC e abastecimento

**Role / Papel / Rol:** App Android com NFC para pista  
**Stack:** `Java (Android), NFC, sync`

#### Problem / Problema
Abastecimento e identificação na pista precisavam ser rápidos e à prova de falha de digitação — idealmente por tag NFC.

#### Solution / Solução / Solución
App Android com leitura NFC, gestão de veículos/motoristas/frentistas e sincronização com o backend de frota.

#### Highlights
- Leitura de tags NFC
- Controle de abastecimento
- UI em abas (ViewPager)
- Sync com servidor
