## 🇧🇷 Português

### Integração STOP — TXT para contabilidade

**Role / Papel / Rol:** Integração de movimentações via arquivo  
**Stack:** `Delphi/Pascal, arquivos TXT, contabilidade`

#### Problem / Problema
Movimentações de rede de postos precisavam chegar ao escritório contábil em formato TXT consumível pelo sistema contábil.

#### Solution / Solução / Solución
Aplicação Delphi que transforma movimentações em arquivos TXT no layout esperado pela contabilidade, com execução repetível.

#### Highlights
- Exportação TXT confiável
- Ponte operação → contabilidade
- Delphi em produção
