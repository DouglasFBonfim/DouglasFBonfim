## 🇧🇷 Português

### DigitalizaApp — SaaS + currículo online

**Role / Papel / Rol:** Produto próprio: API multi-tenant, deploy VPS e página de currículo  
**Stack:** `Python FastAPI, PostgreSQL, Docker, Caddy/HTTPS, HTML/JS`

#### Problem / Problema
Precisava de uma plataforma própria (agendamento/gestão multi-empresa) e de um currículo web exportável em PDF, em vários idiomas, acessível a recrutadores.

#### Solution / Solução / Solución
SaaS com FastAPI + PostgreSQL + Docker na VPS (digitalizaapp.tech) e currículo estático público no GitHub Pages, sem expor código sensível do produto.

#### Highlights
- Currículo online: https://douglasfbonfim.github.io/curriculo/
- Produção: https://digitalizaapp.tech/curriculo
- Exportação PDF (imprimir) PT/EN/IT
- Código do SaaS permanece privado

## 🇬🇧 English

### DigitalizaApp — SaaS + online resume

**Role / Papel / Rol:** Own product: multi-tenant API, VPS deploy and resume page  
**Stack:** `Python FastAPI, PostgreSQL, Docker, Caddy/HTTPS, HTML/JS`

#### Problem / Problema
I needed my own multi-company scheduling/management platform and a web resume exportable to PDF, multilingual, reachable by recruiters.
