## 🇧🇷 Português

### Digitaliza System — gestão comercial/financeira

**Role / Papel / Rol:** Sistema completo (web local + desktop empacotado)  
**Stack:** `Python, HTML/JS/CSS, SQLite/local DB, PDF/Excel, Windows exe`

#### Problem / Problema
Pequeno varejo precisava unificar cadastros, pedidos, vendas, compras e contas a pagar/receber em um só ambiente Windows, com relatórios e auditoria.

#### Solution / Solução / Solución
Entreguei aplicação web local empacotável, com relatórios PDF/Excel, trilha de auditoria e automações de aviso (e-mail/WhatsApp) sem depender de nuvem obrigatória.

#### Highlights
- Gestão comercial + financeira
- Relatórios PDF/Excel
- Auditoria de dados
- Executável Windows

## 🇬🇧 English

### Digitaliza System — sales/finance management

**Role / Papel / Rol:** Full system (local web + packaged desktop)  
**Stack:** `Python, HTML/JS/CSS, SQLite/local DB, PDF/Excel, Windows exe`

#### Problem / Problema
A small retailer needed one Windows environment for catalogs, orders, sales, purchases, and payables/receivables — with reports and audit.

#### Solution / Solução / Solución
I delivered a packable local web app with PDF/Excel reports, audit trail, and notification automations (email/WhatsApp) without mandatory cloud.

#### Highlights
- Sales + finance management
- PDF/Excel reports
- Data audit
- Windows executable
