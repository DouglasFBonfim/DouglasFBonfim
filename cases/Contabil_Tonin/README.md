## 🇧🇷 Português

### Integração contábil — planos de contas

**Role / Papel / Rol:** Conversão/mapeamento de planos de contas  
**Stack:** `Delphi, PostgreSQL, UniDAC`

#### Problem / Problema
Empresas diferentes usavam planos de contas distintos; era preciso mapear e sincronizar contas sem planilha manual frágil.

#### Solution / Solução / Solución
Sistema Delphi + PostgreSQL para gerenciar tabela de conversões, sincronizar colunas por empresa e registrar logs.

#### Highlights
- Mapeamento multiempresa
- PostgreSQL + UniDAC
- Logs operacionais

## 🇬🇧 English

### Accounting integration — chart of accounts

**Role / Papel / Rol:** Chart-of-accounts conversion/mapping  
**Stack:** `Delphi, PostgreSQL, UniDAC`

#### Problem / Problema
Different companies used different charts of accounts; mapping/sync was needed without fragile spreadsheets.

#### Solution / Solução / Solución
Delphi + PostgreSQL system to manage conversion tables, sync columns per company, and keep logs.

#### Highlights
- Multi-company mapping
- PostgreSQL + UniDAC
