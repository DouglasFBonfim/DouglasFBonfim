## 🇧🇷 Português

### Ponto BR — agendamento de e-mails/SQL

**Role / Papel / Rol:** Backend de agendamento e envio  
**Stack:** `Python, PostgreSQL, SMTP, agendamentos`

#### Problem / Problema
Relatórios precisavam sair automaticamente por e-mail a partir de consultas SQL, com horários recorrentes e rastreio de execução.

#### Solution / Solução / Solución
Implementei serviço Python que agenda consultas, formata resultados e envia e-mails, com schema dedicado e logs de execução.

#### Highlights
- Agendamentos diário/semanal/mensal
- PostgreSQL + SMTP
- Logs de execução auditáveis
